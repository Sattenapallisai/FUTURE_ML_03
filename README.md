# Resume Screening System

A Machine Learning-based Resume Screening System built using Python, Pandas, and Scikit-learn.  
This project automatically analyzes resumes, compares them with a job description, and ranks candidates based on similarity scores.

---

## Features

- Resume text processing
- Job description matching
- Candidate ranking system
- Similarity score calculation
- Simple and beginner-friendly implementation

---

## Technologies Used

- Python
- Pandas
- Scikit-learn
- NLP Concepts

```bash

```

Run the project using:
